# Enterprise DevSecOps Platform

An end-to-end DevSecOps platform integrating application development,
continuous integration, security automation, infrastructure provisioning,
containerization, Kubernetes deployment and monitoring.

## Technologies

- Git and GitHub
- Python and Flask
- Docker
- Jenkins
- SonarQube
- Gitleaks
- Trivy
- Terraform
- AWS
- Kubernetes
- Helm
- Argo CD
- Prometheus
- Grafana
